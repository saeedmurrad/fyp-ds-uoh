# Notebooks

| Notebook | Purpose |
|----------|--------|
| `dr-detection-training-final_updated.ipynb` | **Binary** DR (No vs DR), three backbones, metrics + plots → `results/`. |
| `final/dr_binary_detection_thesis_final.ipynb` | Same pipeline + thesis summary cell. |
| `fyp_ds_uoh.ipynb` | Lightweight **setup** stub for multi-class / future work. |
| Other `dr-detection-*.ipynb` | Exploratory or variant runs (sizes, EDA, etc.). |

**Running locally:** from the **repository root**, with `data/` and Kaggle files in place, open the notebook and run all. **Outputs** go to `../results/`.

**Kaggle:** outputs default to `/kaggle/working/results` for download; keep the `OUTPUT DIRS` cell at the top.
